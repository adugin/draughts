# Русские шашки — справка

## Правила игры

Русские шашки — настольная игра для двух игроков на доске 8×8. Вы играете
белыми (снизу), компьютер — чёрными (сверху).

- Шашки ходят **по диагонали на одну клетку вперёд**.
- **Дамка** (коронованная шашка) ходит на любое расстояние по диагонали.
- **Взятие обязательно**. Если можно побить шашку противника — вы обязаны
  это сделать. При взятии шашка перепрыгивает через вражескую по диагонали.
  Возможны множественные взятия за один ход.
- Шашка становится дамкой, достигнув **последнего ряда** доски. Если
  превращение происходит во время серии взятий — шашка продолжает бить уже
  как дамка.
- Побеждает тот, кто побил все шашки противника или лишил его возможности
  сделать ход.

### Когда объявляется ничья

- Троекратное повторение позиции.
- 1 дамка против 1 дамки (недостаточно материала).
- 2 дамки против 1 дамки (треугольник Петрова).
- 15 ходов только дамками без взятий.
- 30 ходов без взятий и движения шашек.

## Управление мышью

- **Левая кнопка** — выбрать шашку, указать позицию хода, промежуточное
  взятие (всё через левый клик).
- **Правая кнопка** — отменить выбор шашки.

### Простой ход

1. Щёлкните левой кнопкой по своей шашке — она выделится.
2. Щёлкните левой кнопкой по клетке, куда хотите пойти.

### Взятие

1. Щёлкните левой кнопкой по шашке, которая будет бить.
2. Щёлкните левой кнопкой по конечной клетке — взятие автоматическое.
3. Если путь неоднозначен — промежуточные точки указываются левым кликом.

Чтобы отменить выбор — щёлкните правой кнопкой или выберите другую шашку.

## Меню

### Игра

| Пункт | Хоткей | Описание |
|---|---|---|
| Новая игра | `Ctrl+N` | Начать партию заново. |
| Открыть… | `Ctrl+O` | Загрузить сохранённую партию. |
| Сохранить… | `Ctrl+S` | Сохранить текущую партию в PDN. |
| База партий (PDN)… | `Ctrl+D` | Браузер многопартийных PDN-файлов. |
| Отмена хода | `Ctrl+Z` | Отменить последний ход. |
| Подсказка | `Ctrl+H` | Показать лучший ход с основной линией. |
| Сменить сторону | `Ctrl+F` | Поменяться цветом с компьютером; доска переворачивается. Доступно только на вашем ходе. |
| Сдаться | — | Признать поражение и завершить партию. |
| Опции… | `Ctrl+,` | Сложность, движок, интерфейс, анализ. |
| Выход | `Alt+F4` | Выйти из программы. |

### Позиция

| Пункт | Хоткей | Описание |
|---|---|---|
| Редактор… | `Ctrl+E` | Расставить фигуры на доске. |
| Копировать FEN | `Ctrl+Shift+C` | Скопировать позицию в буфер обмена. |
| Вставить FEN | `Ctrl+Shift+V` | Загрузить позицию из буфера обмена. |

### Вид

| Пункт | Хоткей | Описание |
|---|---|---|
| Панель анализа | `F3` | Оценка текущей позиции и лучший ход. |
| Дерево вариантов | `F4` | Структура загруженной PDN-партии. |
| Просмотр партии… | `Ctrl+R` | Воспроизвести все ходы. |
| Проанализировать партию… | — | Аннотации всех ходов с оценкой. |

### Инструменты

- **Решать задачи…** (`Ctrl+P`) — тренажёр тактических задач.
- **Импорт книги из PDN…** — построить дебютную книгу из своих PDN-файлов
  (30 сек – 10 мин). Результат сохраняется в пользовательскую папку и
  автоматически подхватывается движком вместо встроенной книги.
- **Добыча тактических задач…** — сыграть N self-play партий и извлечь
  тренировочные задачи (5 – 60 мин). Новые задачи появляются в тренажёре
  вместе со встроенными.
- **Скачать расширенную базу эндшпилей…** — загрузить готовую базу на
  4 фигуры (~126 МБ) с GitHub Releases. Файл сохраняется в
  пользовательскую папку и подхватывается движком автоматически.

### Справка

- **Информация** (`F1`) — эта справка.
- **Об авторе** — информация об авторе программы.

## Опции

Настройки сохраняются автоматически и загружаются при следующем запуске.

### Вкладка «Игра»

- **Сторона** — играть белыми или чёрными.
- **Уровень** — сила компьютера по шкале приблизительного Эло:

  | Уровень | Название | Эло | Глубина |
  |---|---|---|---|
  | 1 | Новичок | ~800 | d2 |
  | 2 | Любитель | ~1100 | d3 |
  | 3 | Клубный | ~1400 | d4 |
  | 4 | Сильный клубный | ~1700 | d5 |
  | 5 | Кандидат | ~2000 | d6 |
  | 6 | Мастер | ~2200+ | d8 |

- **Подсказка взятия** — подсвечивать, когда взятие обязательно.

### Вкладка «Движок»

- **Хэш-таблица** — размер таблицы транспозиций в МБ. Применяется со
  следующего хода компьютера.
- **Дебютная книга** — использовать книгу дебютов (~47 000 позиций).
- **Эндшпильная база** — использовать базу эндшпилей (3 фигуры встроено;
  4 фигуры — через меню **Инструменты → Скачать…**).
- **Глубина (dev)** — ручная глубина поиска (только для разработчиков).

### Вкладка «Интерфейс»

- **Тема оформления** — 7 тем на выбор.
- **Скорость анимации** — пауза между ходами для наглядности.
- **Координаты** — буквенно-цифровые метки клеток (a–h, 1–8).
- **Подсветка хода** — маркер последнего хода.
- **Возможные ходы** — точки допустимых ходов при наведении курсора.

### Вкладка «Анализ»

- **Панель анализа** — `F3` или меню **Вид → Панель анализа**.
- **Анализ партии** — меню **Вид → Проанализировать партию…**.

## Редактор позиций

Вход: `Ctrl+E` или меню **Позиция → Редактор**.

- **Левый клик** — циклически: пусто → чёрная → чёрная дамка → белая →
  белая дамка → пусто.
- **Правый клик** — очистить клетку.

### Кнопки редактора

| Кнопка | Действие |
|---|---|
| ▶ Играть | Начать игру из текущей позиции. |
| Анализ | Проанализировать текущую позицию. |
| Отмена | Вернуться к предыдущей партии (или `Escape`). |
| Очистить | Убрать все фигуры. |
| Начальная | Стандартная расстановка. |
| Импорт FEN | Загрузить позицию из текста. |
| Экспорт FEN | Скопировать позицию в буфер обмена. |

### Валидация

При нажатии **Играть** или **Анализ**:

- Пешки на последнем ряду автоматически превращаются в дамки.
- Доска не может быть пустой.
- У обеих сторон должны быть фигуры.

## Командная строка

```
python main.py                    — новая игра
python main.py game.pdn           — загрузить партию из PDN
python main.py --resume           — продолжить прерванную партию
python main.py --difficulty 4     — установить уровень (1–6)
python main.py --black            — играть чёрными
python main.py --version          — показать версию
```

Параметры можно комбинировать:

```
python main.py game.pdn --difficulty 3 --black
```
